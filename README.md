# Power Habits

Aplicación móvil personal en **Flutter (Local-First → Supabase)** para construir disciplina diaria con claridad, control de progreso y estética **Soft Glass Minimal** (`ui-ux-pro-max`).

## Características principales

- **Vista Hoy unificada:** Filtro rápido `Todo | Personal | Laboral`, tira semanal de días, barra de progreso diaria y bloques *Mañana / Tarde / Noche / Sin hora*.
- **Rutinas flexibles (A):** Frecuencia diaria, interdiaria (cada 2 días) y días específicos de la semana.
- **Múltiples recordatorios locales (B):** Varias horas por rutina/tarea con acciones rápidas (*Marcar hecho* / *Posponer 30 min*).
- **Calendario de constancia mensual (C) y estadísticas (D):** Cuadrícula visual por rutina y cumplimiento separado entre *Personal* y *Laboral*.
- **Metas por unidades (E):** Línea de progreso con hitos (`0% / 25% / 50% / 75% / 100%`), avance `+1` en 1 toque y pasos/clases nombrados opcionales.
- **Notas rápidas (F):** Registro breve de 1 línea al completar cualquier rutina o tarea.
- **Logros:** Línea de tiempo unificada con hitos automáticos y logros manuales.
- **Widget Android 4×2 (G):** Progreso del día y rutinas pendientes desde la pantalla de inicio.
- **Auto-actualización desde `main`:** Comprobación in-app contra GitHub Releases, descarga del APK `arm64` con progreso e instalación nativa Android.
- **Backup local JSON:** Exportar/importar todos tus datos sin fricción.
